A Google Cloud Platform project with an OAuth consent screen configured for an external user type and a publishing status of "Testing" is issued a refresh token expiring in 7 days, unless the only OAuth scopes requested are a subset of name, email address, and user profile (through the  userinfo.email, userinfo.profile, openid  scopes, or their  OpenID Connect equivalents ).  There is currently a limit of 100 refresh tokens per Google Account per OAuth 2.0 client ID. If the limit is reached, creating a new refresh token automatically invalidates the oldest refresh token without warning. This limit does not apply to  service accounts .  There is also a larger limit on the total number of refresh tokens a user account or service account can have across all clients.
