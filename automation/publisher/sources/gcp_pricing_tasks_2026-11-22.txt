Billable operations   A billable operation is an API call or push delivery attempt.  Item  Price (USD)  Billable operations (chunked at 32 KB)  0 count to 1,000,000 count $0.00 (Free) / 1,000,000 count, per 1 month / account 1,000,000 count and above $0.40 / 1,000,000 count, per 1 month / account   Billing notes   Note the following:  API calls that work on multiple tasks are accounted for as multiple billable operations; for example, one list request fetching 25 tasks is charged as 25 billable operations.
