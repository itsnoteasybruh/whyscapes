You can configure authentication at the queue level by setting the  httpTarget  override (specifically the oauthToken  or oidcToken fields). If authentication is configured at the queue level, this configuration overrides any authentication configured at the task level. For example, if a queue has an OIDC token override configured, tasks added to that queue with OAuth tokens will dispatch with the queue-level OIDC token.  To configure authentication at the task level, specify either an ID token, or an access token, in the  task  itself.
